\# ServicePro Management Platform



ServicePro is a web-based service management platform designed to centralize customer requests, quotations, bookings, field service execution, invoicing, payments, and reviews.



\## Project Architecture



\- Frontend: React + Vite

\- Backend: Node.js + Express.js

\- Database: MongoDB

\- Architecture: Web-based SaaS
